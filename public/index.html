GitHub npm

Install

npm install embed-lite

Import

import { embed } from 'embed-lite';

Basic usage

const result = embed('https://youtube.com/watch?v=dQw4w9WgXcQ');

if (result) {
  console.log(result.html);
  // <iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ" ...></iframe>
}

With options

const result = embed(url, {
  className: 'my-embed-wrapper'
});
